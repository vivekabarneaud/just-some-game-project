# Lore

**`TIMELINE.md` is the single authority.** Everything else in this folder is a
*thread* — depth on one subject, subordinate to the timeline. Where a thread and
the timeline disagree, the timeline wins and the thread is wrong.

| File | Thread |
|---|---|
| **TIMELINE.md** | **The spine, and the authority.** Working canon: the Eternal Court, the Sundering, the two-zone Wastes, the ages down to now. |
| EIGHTH_GOD.md | The forgotten god of Malice — the reframe that made the Sundering deliberate rather than accidental. Late-reveal material. |
| FACTIONS.md | Factions, races, and the standing NPC cast. **Scoped to that** — its old cosmology sections are superseded by TIMELINE; read them as history, not canon. |
| VAREK.md | Varek and his ghost court. **Nothing of it exists in code**, and it carries known canon breaks — see its header before building from it. |
| FOUNDERS.md | The six who came with the Lord. Parallel authority for them specifically. |
| OPEN_IDEAS.md | The holding pen. Nothing here is canon until it's in the timeline. |

`docs/cast/` is the sibling folder: per-character canon for the **recruitable**
cast and NPCs. Its README defers here.

## The rules that keep this usable

1. **One authority.** A fact lives in the timeline. Threads add depth, never contradict.
2. **Threads say what they're for**, in a header, including what's unbuilt or unreliable.
3. **A thread that's wrong is worse than no thread** — it costs you every time you read it. Fix it or delete it.
